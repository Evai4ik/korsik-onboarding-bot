# Корсик — помощник для адаптации сотрудников

**Корсик** — прототип чат-бота в мессенджере **MAX** для знакомства новых сотрудников с компанией, поддержки адаптации и помощи HR-специалистам.

## Стек и архитектура

`MAX → Webhook Make → Data Store + Router Make → Dify (LLM/RAG) → MAX API`

- **MAX**: чат-интерфейс с inline-кнопками.
- **Make**: маршрутизация сообщений, отправка ответов, регистрация, проверка ролей и хранение состояния.
- **Dify**: ответы на свободные вопросы и подключаемая корпоративная база знаний (RAG).
- **Make Data Store (`Korsik Conversations`)**: профиль сотрудника, статус регистрации и адаптации, идентификатор диалога Dify, роль пользователя.

## Функции в экспортированной версии

**Сотрудник:** главное меню, первый рабочий день, информация о компании, правила работы, контакты, регистрация и просмотр личной адаптации; свободные вопросы через Dify.

**HR:** отдельное меню по роли `hr` в Data Store, просмотр списка зарегистрированных сотрудников и сводки этапов их адаптации. Меню также содержит кнопки «Отчёты», «Напоминания», «База знаний», но наличие кнопки само по себе не означает готовность обработчика. В данном экспорте полноценные обработчики этих трёх пунктов не подтверждены.

**Примечание о состоянии:** это Blueprint-экспорт сценария, а не автономно запускаемое приложение. Скриншоты испытаний и инструкции по развёртыванию могут дополнять репозиторий. Автоматическое приветствие по `bot_started` не входит в эту версию.

## Состав репозитория

- [`make/korsik.make.blueprint.sanitized.json`](make/korsik.make.blueprint.sanitized.json) — очищенный экспорт сценария Make.
- [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) — подключение сервисов, ограничения и проверки.
- `.env.example` — перечень необходимых секретов (только заглушки).

## Как продемонстрировать

1. Открыть Корсика в MAX и вызвать «Главное меню».
2. Показать типовые вопросы по правилам работы или компании, поступающие в Dify.
3. Открыть «Моя адаптация» и показать регистрационную анкету / профиль.
4. Для заранее назначенного HR-пользователя показать отдельное меню, «Сотрудники» и «Адаптация сотрудников».

## Безопасность и ограничения

- В публичном Blueprint удалены значения заголовков авторизации MAX; внутренние идентификаторы подключений, Data Store, схем, сертификатов и webhook заменены заглушками.
- **Не публикуйте исходный экспорт**: в нём были действующие токены. Токен MAX необходимо перевыпустить, а старый отозвать.
- HR-доступ предоставляется только через доверенную запись в Data Store. Перед реальной эксплуатацией необходимы аудит прав, политика обработки персональных данных, журналирование и проверка изоляции ролей.
- Корпоративные документы для RAG не включены: их публикация возможна только с разрешения правообладателя / организации.
- Dify-приложение и база знаний в этом архиве не экспортированы; их нужно подключить отдельно.

## Происхождение

Blueprint основан на фактическом экспорте пользовательского сценария Make, подготовленном для демонстрации проекта. Удаление идентификаторов среды означает, что потребуется ручная перенастройка связей при импорте.
